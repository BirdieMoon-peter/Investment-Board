# 策略研究与模拟跟踪

策略工作区将研究假设、历史实验与后续模拟账户连接到同一个投资看板。覆盖沪深 A 股和场内 ETF／LOF 的日频、多头与现金配置；实际持仓记录和策略模拟账本分别保存。

## 从规则到复盘

1. **定义策略**：选择模板、标的范围、观察窗口、调仓规则、初始资金与成本假设，保存策略版本。
2. **准备数据**：独立获取原始日线或导入数据快照，检查日期、价格口径、单位、交易规则及公司行动覆盖。
3. **运行实验**：用收盘后的信号安排后续交易日开盘成交，查看净值、基准、回撤、订单和拒单原因。
4. **检查稳健性**：比较时间顺序划分的样本外表现、邻近参数和提高成本后的结果。
5. **模拟跟踪**：从账户创建日与快照末日的较晚日期之后记录后续会话，显式推进并复查实验假设。

## 策略模板

| 模板 | 规则重点 | 比较对象 |
| --- | --- | --- |
| ETF 动量轮动 | 在声明的基金范围内按历史动量选择配置对象，按周期调仓并限制单标的权重 | 同一基金范围的等权配置 |
| 均线趋势 | 根据历史均线关系在标的与现金之间切换 | 同一标的持有策略 |
| ETF 均值回归 | 根据相对历史均值的偏离进入或退出持仓 | 同一标的持有策略 |

模板是可复核的规则集合，不预设哪一种具有超额收益。策略版本保存后，后续参数修改形成新版本；旧实验继续引用原来的规则和数据。

## 数据与收益口径

量化行情与已有标的研究行情分别保存。已有前复权价格用于研究图表，不能直接代替模拟成交价格；量化接入使用独立原始日线快照，以人民币价格和股／份数量记录。原始来源、获取时间、证券规则、观察会话和公司行动声明均随快照保存。

回测结果依赖数据覆盖和声明的交易条件。未知分红／拆并份覆盖时，结果应按带限制的价格研究实验理解，不能视为已经核验的含分红总收益。用户输入的完整覆盖声明仍然是数据假设，不等于交易所历史认证。当前模板不使用最新财报倒填历史信号，也不让当前大模型生成过去日期的交易决策。

当前实验使用用户声明的固定标的范围和获取时保存的日线快照，尚未重建历史指数成分、退市证券范围及每条行情最初的可得版本。快照保证本次实验可以复核，但不能据此认定已经排除幸存者偏差或所有历史数据修订影响。每份快照最多覆盖 8 个标的、600 个观察会话；规则与日线成交假设须结合具体研究窗口核对。

缺少当日行情、没有有效成交量、资金不足或不满足交易条件时，不补造订单成交。陈旧价格只能用于带说明的估值。策略资金、佣金、最低费用、卖出税费、滑点、成交量上限、整手数量、可卖出时间和价格限制应一并检查。

历史费用不能仅凭当前默认值认定：例如证券交易印花税自 2023 年 8 月 28 日实施减半征收，ETF 交易与股票交易的收费范围也不同。实验使用的费用参数仍须与标的和研究日期核对。[财政部、税务总局公告](https://www.mof.gov.cn/jrttts/202308/t20230828_3904235.htm)、[上交所 ETF 交易介绍](https://etf.sse.com.cn/fund/learning/knowledge/c/5704298.shtml)。

## 历史实验与模拟账户

历史实验冻结数据、策略、成本和计算版本。基准采用同一数据范围与交易条件，结果附带成交依据及未成交原因。时间顺序的样本外窗口用独立初始资金计算，较早数据仅作为指标预热输入；参数邻域和提高成本检查用于暴露结果对假设的敏感性。

模拟账户从创建时点向后推进，不将过去回测利润作为新账户的已实现收益。新数据必须延续已经冻结的历史；如果旧行情或规则发生修订，应作为新的研究数据处理，不能覆盖已有模拟账本。重复推进同一观察范围不应重复成交。

刚创建的账户通常显示“等待后续行情”：导入截至过去日期的数据不会自动产生前向收益。后续获取或导入兼容快照，再显式推进账户。原始数据采集受数据中心的东方财富来源开关控制；来源不可用时，可保留已有快照，并通过有来源说明的 JSON 文件导入继续研究。

实际持仓与目标配置的比较仅用于本地研究，不修改持仓数量或成本，不连接券商，也不提交真实订单。

## 实验研究与证据

AI 实验研究由用户显式生成，输入限于保存的实验事实、规则、指标和限制。数值计算由确定性引擎负责；报告将事实、推断、假设与待验证条件区分展示，并核对引用及结构化数值。生成报告不会将实际持仓自动加入实验输入。

复盘时结合样本外结果、交易成本、拒单、数据缺口和后续模拟记录判断假设是否继续成立。单次回测或某一组参数的高收益，不能替代持续的样本外证据。

接口与导入结构见 [量化 API 文档](../quant-api.md)。
