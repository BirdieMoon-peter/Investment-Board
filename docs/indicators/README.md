# 指标计算与输入口径

Investment Board 使用确定性计算服务生成指标，模型不负责计算金融数值。每项结果包含公式及版本、观察窗口、单位、样本数、输入来源、观察日期和限制说明。结果状态为 `ready` 或 `unavailable`；缺失结果不会以零替代。

## 价格与成交量

| 指标 | 计算方式 | 输入条件 |
| --- | --- | --- |
| 20／60／252 观察日价格收益 | `末日收盘价 / 首日收盘价 - 1` | 分别需要 21／61／253 个有序、有效收盘价，来源、日频单位与价格口径已确认 |
| 窗口最大回撤 | `min(当前价 / 截至当日的窗口最高价 - 1)` | 至少两个有效价格；窗口从本地读取的有界序列起点开始 |
| 年化样本波动率 | `日简单价格收益的样本标准差 × √252` | 至少 20 个日收益；252 为年化约定 |
| MA20／MA60、均线偏离 | `窗口收盘价均值`；`最新收盘价 / 均值 - 1` | 完整窗口及一致价格口径 |
| 量能比 | `最新成交量 / 此前20个观察日的平均成交量` | 21 个有效观察值，成交量单位统一且已确认；分母不包含最新一天 |

价格收益不包含红利再投资。目前未接入经核验的交易日历，观察日不构成完整交易日覆盖保证；可能的停牌或日期缺口会单独标注。指数使用点位，当前已接入指数数据的复权与成交量口径尚未核验，不据此生成正式价格表现指标或现金持仓估值。

## 财务比较

财务同比只比较明确识别的同季度累计报告，例如当年三季报与上年三季报。未知报告期间不按日期或名称猜测；同比增长要求上期基数为正，零基数或亏损基数保留缺口及经营情况说明。

现有净利润字段为归属于母公司股东的净利润，因此相关比率标注为 **归母净利润／营业收入**，不称为整体净利率。ROE 保留来源提供的百分数值；未提供的资产负债率不由其他字段推算。

## 场内 ETF／LOF

正式折溢价要求同一日期的已确认未复权收盘价与官方单位净值，且单位匹配。现有东方财富历史价格采用前复权口径，因此不会直接与原始净值相除。单位净值、累计净值及参考 IOPV 分别处理，累计净值不自动视作红利再投资收益。

基准使用显式、带市场前缀的映射，例如 `SH:000300`，不按名称推断。总收益比较与跟踪误差需要对齐的基金、基准红利再投资序列；跟踪误差至少需要 60 个有效对齐日收益。目前缺少该口径时，结果明确显示无法计算。取得指数行情本身不会满足这一条件。

## 当前持仓

市值为 `数量 × 已保存最新价`，未实现盈亏为 `数量 × (最新价 - 平均成本)`。价格需要对应已确认的股票或场内基金、人民币单位及实际采集观察时间。每个仓位保留估值时点，跨仓位日期可能不同。

权重与集中度仅使用 **已知可估值持仓** 的合计市值作为分母。缺少有效价格的仓位另列，整体估值标记为不完整。集中度为权重平方之和，不是预测风险评级。没有交易流水时，不生成历史组合收益或已实现收益。

## 只读接口

- `GET /api/indicators/securities/{security_id}`：标的指标及数据口径。
- `GET /api/indicators/holdings`：当前仓位估值、权重、集中度及缺口。

这两个接口只读取本地保存的数据，不调用外部采集服务或 AI。陈旧数据可用于注明日期的历史观察，但不会因一次页面读取而变成实时数据。
