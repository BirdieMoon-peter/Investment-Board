# 证据驱动的 AI 研究

研究工作区面向单一股票或场内 ETF／LOF 的研究问题。它将问题与假设、输入快照、支持证据、反证和后续检查组织为研究卡，保留分析产生时的数据背景，方便后续复查。

## 工作流程

1. 保存研究问题，可附带假设和观察期限。编辑使用版本检查，避免覆盖其他窗口的修改。
2. 显式生成研究报告。系统先冻结本地输入，再调用网页配置的模型；个人持仓不包含在该研究上下文中。
3. 阅读事实、推断和假设，展开支持证据与反证，并检查数据缺口、失效条件及下一步观察。
4. 数据更新后，手动复查已保存观点。系统比较当前本地输入与存档快照，并检查可计算的指标条件，形成去重的复查事件。
5. 完成人工复查后确认事件。确认不会改写历史报告；归档的问题仍可回看历史。

## 快照与证据

每次报告保存当时的问题版本、数据输入、指标、模型名称及提示词版本。后续行情或资料变化不会替换旧报告的输入。模型生成失败时保留已冻结的输入及受控错误原因。

证据区分来源、观察期间、实际已知的发布时间和获取时间；文档标题与内容摘要分别标注。未知单位、价格口径或来源归属不会因进入 AI 上下文而变成已验证数据。研究上下文有明确数量和长度上限，不宣称穷尽全部资料。

## 三种检查分别展示

| 检查 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 引用存在性 | 引用是否属于这次报告保存的证据或指标 | 文本是否被证据充分支持 |
| 结构化数值核对 | 报告提交的指标数值是否与确定性计算结果一致 | 所有自然语言数值或投资判断都正确 |
| 可选模型语义复核 | 模型对支持、反证与不确定性的解释 | 经过独立验证的事实、预测胜率或保证收益 |

标题不能作为数值事实的充分依据。模型复核不可用时，主报告仍保留，并明确显示复核缺口，不将结果标为全面验证。

## 观点复查的边界

数据变化表示 **需要复查**，不等于原观点已被证伪。指标条件只比较已接入、可计算的指标及有限数值阈值；定性条件、未知指标和缺少输入的条件显示无法自动检查，不执行用户表达式。

复查只读取本地保存的数据，不抓取外部行情，也不调用模型。页面浏览、历史读取和数据同步不会自动生成研究报告。每次显式生成最多调用一次主模型；用户选择语义复核时，最多增加一次模型调用。

本工作区不提供自动交易、策略回测或经过校准的预测概率。金融数值由确定性指标服务提供，模型用于组织解释、提出替代解释和明确尚需验证的假设。
